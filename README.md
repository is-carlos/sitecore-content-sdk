# Sitecore Content SDK Next.js Sample Application

[SitecoreAI Content SDK Documentation](https://doc.sitecore.com/sai/en/developers/content-sdk/sitecore-content-sdk-for-sitecoreai.html)

## Running without Sitecore

Snapshot content with `npm run mock:snapshot -- --site <name>`, then run `npm run dev:mock` to serve it from a local mock GraphQL server. See [scripts/mock-sitecore/README.md](scripts/mock-sitecore/README.md).
